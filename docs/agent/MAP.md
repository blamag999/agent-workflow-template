# Repo map

Short map so agents do not scan the repo. Planner keeps it current at close time.

| Path | Purpose |
|---|---|
| `AGENTS.md` | Rules for every agent session |
| `docs/agent/ADOPT.md` | Onboarding guide (Core vs Scale-up profile) |
| `docs/agent/roles/` | One short file per role (`planner`, `coder`, `reviewer`) |
| `docs/agent/templates/` | Core (`work`, `next-prompt`) + optional Scale-up (`checkpoint`, `reuse`) |
| `docs/agent/work/` | Active work files (one per branch) |
| `docs/agent/archive/` | Closed work files (optional in Core) |
| `docs/agent/INDEX.md` | One line per finished work item (optional in Core) |
