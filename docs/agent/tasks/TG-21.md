## Goal

Fix unsafe defaults and misleading usage metrics in Antigravity Token Guard, while making the existing Tampermonkey userscript safe and usable on ChatGPT and Claude Web without new infrastructure. Keep Token Guard optional and **independent** of Lean Agent Workflow v2.

## Scope

**Plugin TG01–TG06**
1. `.agents/plugins/token-guard/config.json`, `scripts/token_tracker.py`: default `suggest`, remove `avg_delta`/`est_turns_left`, retain signed `delta_tokens`; extract disjoint token-field helper with robust null/malformed handling, cache `parse_transcript` by path/mtime_ns/size, label local usage and configured thresholds truthfully.
2. Existing Side Pane `ui/panel.html`: remove stale forecast binding; text-label tweaks only, avoiding unnecessary bundled rebuild churn.
3. `rules/AGENTS.md`, `skills/token-guard/SKILL.md`: handoff/new-chat functionality opt-in; no coupling to Lean work-file or role-state logic.
4. Plugin/root README: safe download–inspect–run instructions and explicit distinction between observed local usage and official provider quota.
5. Retain installers' existing config preservation; test normal and force modes without new installer architecture.

**Web TG07**
6. `extras/web-token-guard.user.js`: ChatGPT and Claude platform-specific message extractors with deduplication; no whole-page fallback; explicit “estimated visible-text tokens” and uncounted attachments/model context; SPA changes handled; limit MutationObserver churn.
7. Guard editor insertion against overwriting drafts; use compatible input events or clipboard fallback; correctly handle clipboard errors. No transmission of conversation text, API calls or auto-created sessions.

**Out of scope:** actual provider context-window/quota determination for Web, paid tokenizer/AI calls, automatic chat handoff, multi-agent dashboard, Lean v2 changes, deployment and `main` merge.

## Acceptance criteria

- **AC1:** Plugin defaults to `suggest`; no autonomous handoff/creation on threshold.
- **AC2:** Token parsing handles disjoint cache and malformed transcript records consistently for latest/session/5h/7d values; no double-counting under supported schema.
- **AC3:** Forecast removed, signed delta remains; labels state local/observed/estimated nature.
- **AC4:** Unchanged transcript parsed once per unchanged path+mtime_ns+size; changed file re-evaluated.
- **AC5:** PowerShell/Bash normal update preserves user config, force replaces; document unsupported failure edge cases.
- **AC6:** ChatGPT/Claude DOM extraction counts identified conversation messages once and handles missing/changed selectors with “unavailable” instead of false totals.
- **AC7:** Web SPA navigation/streaming updates displayed conversation and avoids observer loops.
- **AC8:** Web draft never silently overwritten; clipboard status reflects actual result.
- **AC9:** No additional outbound conversation-content transmission; separate source semantics explicitly documented.
- **AC10:** Reviewer records real evidence and any unavailable browser/Antigravity runtime tests as NOT RUN, not PASS.
